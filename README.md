# 项目统一标准与分工手册

*智慧气象赛道 · 站点短时强降水预报*

## 一、概括

**数据集用 CIKM 2017（免费、小、快），模型用现代编码器（3D-CNN + 注意力），核心创新聚焦“强降水感知训练”，学长 + 2 名队员三人分工，10/15 前完成提交。**

## 二、数据集标准（主用 CIKM 2017）

| 项目 | 统一标准 |
| --- | --- |
| 数据集 | CIKM AnalytiCup 2017（深圳气象局 + 阿里云 + CIKM 2017 主办） |
| 下载 | 天池平台注册后下载（免费，约 2GB，CC BY-NC-SA 许可） |
| 输入 | 雷达反射率图：15 个时刻（6 分钟间隔）× 4 个高度（0.5/1.5/2.5/3.5km）× 101×101 网格 |
| 输出 | 目标站点（中心点）未来 1–2 小时总降水量 |
| 规模 | 训练 10000 / 测试第一阶段 2000 / 测试第二阶段 2000 |
| 灵活用法 | 对比基线：直接引用 HKO-7 / SEVIR 已发表指标数字，无需下载对应数据集 |

## 三、任务定义

给定过去 90 分钟（15 帧 × 4 高度）的雷达反射率图，预测目标站点未来 1–2 小时的降水量，重点保证对大雨（强降水）的预测精度。

## 四、模型标准

| 角色 | 模型 | 说明 |
| --- | --- | --- |
| 主模型 | 3D-CNN + 注意力（CBAM/SE）编码器 | 现代、易实现；避免“老 ConvLSTM 纯 RNN” |
| 备选主模型 | 轻量 Transformer 编码器（可选加分） | 若时间富余再上 |
| 对比基线 | 经典 CNN 编码器、ConvLSTM、光流法 | 用于“与现有方案对比”，体现改进 |
| 框架 | PyTorch | 统一实现与复现 |

**核心创新点（聚焦一点）：强降水感知训练——用 focal loss / 极端值损失（EVL）/ 分雨量档加权，解决“小雨多、大雨少”的类不平衡，重点提升大雨预测精度。**

## 评价指标标准

| 类别 | 指标 | 说明 |
| --- | --- | --- |
| 回归类 | RMSE / MAE | 总体预测误差 |
| 分档命中 | 小雨 / 中雨 / 大雨 分档 CSI、命中率、误报率 | 核心：重点看大雨档提升 |
| 综合 | 与已发表基线对比（相对提升幅度） | 量化“相对现有方法提升多少” |

## 七、分工（各自干什么）

### 7.1 学长

- 方向与创新点最终定调。
- 给出“强降水感知损失”的具体数学形式与实现要点（focal/EVL 公式、分档加权方案）。
- 作品方案“创新性(25分)+AI技术(20分)”两部分的技术审校与表述把关。

### 7.2 队员①（数据 + 模型 + 训练）

- 天池下载 CIKM 2017 数据并做预处理（切片、归一化、Z-R 转换）。
- 实现 3D-CNN + 注意力编码器，跑通训练。
- 实现“强降水感知训练”模块（focal/EVL/分档加权）。
- 训练、调参、记录消融实验（基线 vs +强降水感知）。

### 7.3 队员②（评价 + 文档 + 材料）

- 搭建评价脚本（RMSE/MAE + 分档命中/CSI）。
- 生成图表：对比表、消融表、预测误差分布图。
- 撰写作品方案（按官方模板六章结构）。
- 制作答辩 PPT、录制演示视频、打包网盘并提交。
